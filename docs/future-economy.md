# Economia futura

Este documento regista apenas a direção futura. Não existem preços, carteira, recompensas ou loja implementados.

`Souls` é um recurso limitado de combate, com máximo de cinco, e não deve ser confundido com a moeda económica futura.

Uma evolução possível será:

```text
resultado autoritativo da partida -> recompensa virtual -> carteira -> loja -> coleção -> Deck Builder
```

A carteira e a loja devem ser responsabilidades separadas do catálogo, da coleção e dos baralhos. As transações e recompensas terão de ser validadas pelo backend quando existir uma sessão online. O frontend não deve ser autoridade sobre saldo ou propriedade.
