# Identidade visual

## Direção

SOULS utiliza uma direção **Dark Fantasy Medieval — Intensidade Cinematográfica**.

A interface combina:

- pedra escura;
- ferro negro;
- bronze envelhecido;
- dourado antigo;
- vermelho brasa;
- energia azul-violeta para Souls;
- profundidade através de gradientes e sombras suaves.

A estética é aplicada como camada de apresentação. Não altera regras, valores ou estados do jogo.

## Aplicação atual

- superfícies com gradientes de ferro e pedra;
- molduras bronze/dourado em painéis, cartas e tabuleiro;
- cores funcionais distintas para defesa, melee e ranged;
- cartas melee com acentos quentes;
- cartas ranged com acentos arcanos;
- seleção e jogador ativo com brilho dourado;
- Souls reservadas para o acento violeta;
- danger reservado para estados de dano/derrota futuros.

As cinco ilustrações PNG das cartas de teste são recursos fornecidos para o protótipo; a moldura, hierarquia e diferenciação por tipo constituem o Visual Base v1, não um catálogo artístico definitivo.
