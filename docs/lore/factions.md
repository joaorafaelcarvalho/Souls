# Facções de Vespera

As facções são metadados narrativos sem bónus, habilidades ou modificadores de combate.

| ID | Facção | Lema |
| --- | --- | --- |
| `last-watch` | Ordem da Última Vigília | Enquanto a última chama arder, permaneceremos. |
| `pale-moon-veil` | Véu da Lua Pálida | A lua revela aquilo que as sombras escondem. |
| `rift-conclave` | Conclave da Fenda | Toda a alma deixa um eco. |
| `sepulchral-oath` | Juramento dos Sepulcros | O que foi selado deve permanecer em silêncio. |
| `ashen-crown` | Coroa das Cinzas | Das cinzas, o trono voltará a erguer-se. |

Os dados estruturados estão em [lore/catalog.ts](../../packages/game-content/src/lore/catalog.ts). A interface visual está no [CodexPage](../../apps/web/src/features/codex/presentation/CodexPage.tsx).
